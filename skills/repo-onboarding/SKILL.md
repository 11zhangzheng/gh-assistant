# Repo Onboarding

Before acting on a repo you haven't worked on, learn its shape:

1. `repo_info` for metadata (description, default branch, open issue count).
2. `list_labels` to learn the repo's label taxonomy — what categories exist.
3. `list_issues` to see what's currently open and how they're labeled.
4. Read the README or ask the maintainer about conventions if it matters for
   the task at hand.
5. Note conventions you learn (label meanings, triage rules) so they can be
   saved to memory for future sessions.
